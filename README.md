# Muyong — หน้าอัปเดตผลงานแปล

เว็บหน้าเดียว static ล้วน ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล
แก้ข้อมูลทั้งหมดที่ `data.json` ไฟล์เดียว

```
muyong-reader/
├── index.html      หน้าเว็บ (ไม่ต้องแก้)
├── data.json       ★ แก้ที่นี่
├── assets/         style.css (สี/หน้าตา), app.js (โค้ด)
└── images/
    ├── banner.webp     แบนเนอร์บนสุด (16:5)
    ├── avatar.webp     รูปโปรไฟล์
    └── covers/         ปกแต่ละเรื่อง (3:4)
```

## เพิ่มเรื่องใหม่

เอาปกใส่ `images/covers/` แล้วเพิ่มก้อนนี้ในลิสต์ `series` ของ `data.json`

```json
{
  "id": "ชื่อภาษาอังกฤษ-ไม่มีเว้นวรรค",
  "title": "ชื่อเรื่องภาษาไทย",
  "genres": ["แฟนตาซี", "วาย"],
  "status": "ongoing",
  "days": ["mon", "thu"],
  "cover": "images/covers/ชื่อไฟล์.webp",
  "readUrl": "https://www.facebook.com/..."
}
```

| ช่อง | ใส่อะไร |
|---|---|
| `id` | ห้ามซ้ำกับเรื่องอื่น ใช้อ้างอิงภายใน |
| `status` | `ongoing` = กำลังแปล · `completed` = ขึ้นหมวดแปลจบแล้ว |
| `days` | วันที่ลง เลือกจาก `mon` `tue` `wed` `thu` `fri` `sat` `sun` ใส่หลายวันได้ ไม่ลงประจำใส่ `[]` |
| `readUrl` | **ลิงก์ที่คนกดปกแล้วไป** — เพจ FB, กลุ่ม, เว็บที่ลงจริง อะไรก็ได้ |

## ซ่อนวันที่ยังไม่มีเรื่องลง

ใน `data.json` ส่วน `site`

```json
"hideEmptyDays": true
```

`true` = ซ่อนวันที่ยังว่าง · `false` = โชว์ครบ 7 วัน
ถ้าไม่มีเรื่องลงสักวัน ตารางจะหายไปทั้งก้อน

**`readUrl` ว่างไว้ได้** ปกจะกลายเป็นรูปเฉยๆ กดไม่ได้ ไม่พัง

## เรื่องจะไปโผล่ตรงไหน

ตัดสินจาก `status` กับ `days` รวมกัน — เรื่องหนึ่งขึ้นที่เดียวเท่านั้น ไม่ซ้ำ

| `status` | `days` | ขึ้นที่ |
|---|---|---|
| `ongoing` | มีวัน เช่น `["tue"]` | **ตารางสัปดาห์** อย่างเดียว |
| `ongoing` | ว่าง `[]` | **กำลังแปลอยู่ตอนนี้** |
| `completed` | อะไรก็ได้ | **แปลจบแล้ว** |

เรื่องที่มีวันลงชัดเจนอยู่ในตารางข้างบนแล้ว เลยไม่เอามาซ้ำในหมวดกำลังแปล
หมวด "กำลังแปลอยู่ตอนนี้" เหลือไว้ให้เรื่องที่ยังไม่มีวันลงประจำ

ถ้าเรื่องที่กำลังแปลมีวันลงครบทุกเรื่อง หมวดนี้จะหายไปทั้งก้อนเอง

## เปลี่ยนแบนเนอร์ / รูปโปรไฟล์

เอาไฟล์ใหม่ทับที่ `images/banner.webp` และ `images/avatar.webp` (ใช้ชื่อเดิม) หรือจะเปลี่ยนชื่อไฟล์แล้วแก้ path ใน `data.json` ส่วน `site` ก็ได้

## ขนาดรูปที่แนะนำ

| อะไร | สัดส่วน | กว้าง |
|---|---|---|
| แบนเนอร์ | 16:5 | 1600 px |
| ปกเรื่อง | 3:4 | 600 px |

ใช้ `.webp` จะเล็กกว่า `.jpg` ราวครึ่งนึงที่คุณภาพเท่ากัน แปลงได้ที่ squoosh.app

## ทดสอบบนเครื่องก่อนอัพ

ดับเบิลคลิก `index.html` จะไม่ทำงาน เพราะเบราว์เซอร์บล็อกการโหลด `data.json` จาก `file://`
ต้องเปิดผ่านเซิร์ฟเวอร์ — เปิด PowerShell ที่โฟลเดอร์นี้แล้วสั่ง

```bash
python -m http.server 8000
```

แล้วเข้า http://localhost:8000

## ระวังตอนแก้ JSON

- ทุกช่องต้องมี `,` คั่น **ยกเว้นช่องสุดท้าย**
- ใช้ `"` เท่านั้น ห้ามใช้ `'` หรือ `"` แบบโค้ง
- แก้เสร็จเช็กว่าไฟล์ยังถูกต้องได้ที่ jsonlint.com — ถ้า JSON พังหน้าเว็บจะว่างเปล่า
